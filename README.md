# Retail Customer Intelligence Dashboard

## Project Overview

This project analyzes retail customer, sales, product, and store data to explore business performance and support data-driven decision-making.

The project uses Microsoft Excel for data auditing, cleaning, and analysis, followed by Microsoft Power BI for data modeling, visualization, and interactive dashboard development.

## Tools Used

- **Microsoft Excel:** Data auditing, quality checks, cleaning, and preliminary analysis.
- **Power BI:** Power Query, data modeling, DAX measures, and interactive visualizations.

## Project Objectives

- Evaluate retail sales performance.
- Explore customer purchasing patterns.
- Analyze product and category performance.
- Compare store performance and geographical distribution.
- Present relevant business metrics through an interactive dashboard.
- Develop evidence-based business insights and recommendations.

## Project Workflow

1. Audited the source data and investigated missing or invalid values.
2. Examined data quality and formatting inconsistencies in Excel.
3. Prepared the data for analysis.
4. Built the Power BI data model and measures.
5. Developed an interactive dashboard with sales and store-performance visualizations.
6. Prepared to document business insights and recommendations.
